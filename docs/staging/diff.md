# Документация: `staging/diff.py` — человекочитаемый diff для пользователя

> Reference-док. Обзор пакета — `_index.md`.

**Назначение.** Единственное место, где пользователь **перед `approve`** видит, что именно предлагается изменить, включая предупреждающие пометки.

## 1. `_DOMAIN_TAG_PREFIX = "domain/"`

Префикс служебного тега домена, который ставит код (`note_assembly.add_domain_tag`).

## 2. `_domain_of(d: DraftNote) -> str` (приватная)

Домен заметки из тега `domain/<домен>`; `""`, если тега нет. Не поднимает.

## 3. `_note_markers(d: DraftNote) -> list[str]` (приватная)

**Возвращает список** строк-пометок (раньше возвращалась одна строка). Пометки:
1. `frontmatter.source == "model-knowledge"` → «⚠ без внешних источников (конспект по знаниям модели)». **У MOC этого ключа нет**, поэтому MOC не помечается;
2. непустой `d.unverified_sections` → «⚠ разделы требуют проверки: …» (перечень заголовков);
3. `d.needs_review` (**legacy**, поле осталось для старых `changeset.json`, Critic удалён) → «⚠ критик не одобрил после N попыт(ки/ок) переписывания — проверьте вручную».

Все сигналы нужны пользователю до `approve`, а не только в логах. Не поднимает.

## 4. `render_diff_summary(changeset: StagingChangeset) -> str`

Полный текстовый diff для консоли. Секции выводятся, только если список непуст:
1. `Задача: <task_id>`;
2. `НОВЫЕ ЗАМЕТКИ (N)`. Для каждой: `+ путь`; для MOC — строка «тип: MOC (оглавление темы)»; заголовок; строка «домен: …» (если есть тег домена); теги **без** `domain/…` (`—`, если пусто); связи `[[…]]`; пометки `_note_markers`;
3. `ДОПОЛНЯЕМЫЕ ЗАМЕТКИ (N)`. Для каждой: `~ путь`; первая строка `append_section` (до 80 символов); пометки. Домен и теги у update не показываются;
4. `⚠️ УДАЛЕНИЯ (N) — по умолчанию заблокированы`;
5. `Новые связи (wikilinks): N`;
6. `Валидация: OK | ЕСТЬ ОШИБКИ (errors=N, warnings=N)` и построчно все issues (`❌` error, `⚠️` warning, формат `[code] message`, `../validation/_index.md`).

**Параметры:** `changeset: StagingChangeset` (`../storage/models.md §5.3`). **Возвращает:** многострочный `str` для `console.print(Panel(...))` в `cli/main.py`. **Исключения:** не поднимает.
