# Документация: `staging/diff.py` — человекочитаемый diff для пользователя

> Reference-док. Обзор пакета — `_index.md`.

**Назначение.** Единственное место, где пользователь ПЕРЕД `approve`
видит, что именно предлагается изменить — включая предупреждающие пометки
(`model-knowledge`, `needs_review`).

## 1. `_note_markers(d: DraftNote) -> str` (приватная)

Строит короткие пометки для ОДНОЙ заметки: (1) режим "без внешних
источников" (`frontmatter.source == "model-knowledge"`), (2) незавершённое
критик-ревью (`d.needs_review`, `../roles/critic.md`). Оба сигнала нужны
пользователю ДО `approve`, а не только в логах.

**Возвращаемое значение:** `str`, напр.
`"⚠ без внешних источников (конспект по знаниям модели)  ⚠ критик не одобрил после 1 попыт(ки/ок) переписывания — проверьте вручную"`,
либо `""`. **Исключения:** не поднимает.

## 2. `render_diff_summary(changeset: StagingChangeset) -> str`

**Описание.** Полный текстовый diff changeset-а для консоли. Секции
(каждая — только если список непуст):
1. `task_id`;
2. `НОВЫЕ ЗАМЕТКИ (N)` — путь, заголовок, теги, связи `[[...]]`, `_note_markers`;
3. `ДОПОЛНЯЕМЫЕ ЗАМЕТКИ (N)` — путь, первая строка `append_section` (до 80
   символов), `_note_markers`;
4. `⚠️ УДАЛЕНИЯ (N) — по умолчанию заблокированы`;
5. `Новые связи (wikilinks): N`;
6. `Валидация: OK|ЕСТЬ ОШИБКИ (errors=N, warnings=N)` + построчно все issues
   (`❌` error, `⚠️` warning, формат `[code] message`,
   `../validation/_index.md`).

**Параметры:** `changeset: StagingChangeset` (`../storage/models.md §5.3`).

**Возвращаемое значение:** `str` — многострочный текст для
`console.print(Panel(...))` в `cli/main.py`. **Исключения:** не поднимает.
