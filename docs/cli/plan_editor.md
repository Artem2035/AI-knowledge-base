# Документация: `cli/plan_editor.py` — интерактивное редактирование плана

> Reference-док. Обзор пакета — `_index.md`.

**Назначение.** Показ и правка `Plan` (`../storage/models.md §1.4`) как `plan_confirm_cb`, сразу после `build_plan`, ДО самого дорогого этапа elaboration. Мутирует `Plan` на месте; `Orchestrator` сохраняет изменённый объект при `persist("plan_approved")`.

## Константы

| Имя | Назначение |
|---|---|
| `_KIND_LABELS_RU` | Русские подписи всех значений `kind` (включая `other`) для выбора типа раздела. |
| `_DOMAIN_LABELS_RU` | Русские подписи доменов для меню смены домена. |

## Функции

- `build_plan_tree(plan) -> rich.Tree` — корень `f"{plan.summary or plan.topic_title}  · домен: {plan.domain}"`, ветви `f"{i}. {note.title}"`, листья `f"{heading} ({kind}): {covers}"`. ⚠ С абзацем `summary` (4–6 предложений) корень получается длинным; если это неудобно, вариант: корень `plan.topic_title`, `summary` печатать отдельно под деревом (решается по итогам приёмки).
- `_prompt_kind(domain, default="other") -> str` — выбор типа раздела из набора домена (`DOMAIN_KINDS`) плюс `other`: нумерованный список с русскими подписями; Enter оставляет `default`; неверный номер печатает ошибку и возвращает прежний тип.
- `_add_note(plan)` — заголовок (пустой = отмена), затем цикл добавления подпунктов (заголовок, `covers`, тип через `_prompt_kind`); заметка добавляется в `plan.notes`.
- `_remove_note(plan)` — номера через запятую или диапазоны (`_parse_indices`), удаление, сообщение с названиями.
- `_rename_note(plan)` — новый заголовок (дефолт — текущий), применяется если непуст.
- `_add_subpoint(plan)` — выбор заметки, `heading` + `covers` + тип; добавляется при непустом `heading`.
- `_remove_subpoint(plan)` — выбор заметки, номера или диапазоны подпунктов.
- `_edit_subpoint(plan)` — правка `heading`, `covers` и `kind` (дефолты — текущие значения).
- `_change_domain(plan)` — выбор домена из `DOMAIN_KINDS`. Смена домена сбрасывает в `other` все `kind`, не входящие в набор нового домена (`normalize_kind`), и печатает число сброшенных. Тот же домен: ничего не меняется. Неверный номер — ошибка.
- `_select_note_index(plan, prompt) -> int | None` — запрос номера (1-based), возвращает 0-based или `None` (пустой план/неверный номер, с сообщением).
- `_select_subpoint_index(note) -> int | None` — печатает нумерованные подпункты, запрашивает номер.
- `_parse_indices(raw, count) -> list[int] | None` — разбор `"2,4,5"`, `"2-4"`, `"1,3-5"` в 0-based индексы **по убыванию, без дублей** (для последовательных `pop()` без пересчёта). Перевёрнутый диапазон (`4-2`) допустим. Границы диапазона проверяются до раскрытия. `None` при нечисле, пустом вводе, `0`, выходе за `[1, count]`, обрыве вида `1-`.

Приватные функции исключений не поднимают (ошибки ввода — через `None` и повторный запрос).

## `_EDIT_MENU`, `_EDIT_ACTIONS`

Меню: 1 — утвердить, 2 — отменить, 3 — добавить заметку, 4 — удалить заметку(и), 5 — переименовать заметку, 6 — добавить подпункт, 7 — удалить подпункт(ы), 8 — изменить подпункт (заголовок/covers/тип), 9 — изменить домен. `_EDIT_ACTIONS` не содержит 1 и 2.

## `confirm_plan(plan: Plan) -> bool`

Цикл: печатает `topic_title`, дерево, счётчики заметок/подпунктов, меню.
- `"1"` — при пустом `plan.notes` ошибка и повтор, иначе `True`;
- `"2"` — `False`;
- прочее — обработчик из `_EDIT_ACTIONS` (мутирует план, затем показ заново) или «Неизвестное действие.».

**Возвращает:** `True` — утверждён, `False` — отмена. Исключений не поднимает.
